# 健身月記｜從每一組，看見一個月的進步

程式設計 作業四：給每週重訓三次的朋友，在健身房用 iPhone Safari（加入主畫面）組間記錄，
下次直接查前次表現，月底用折線圖回顧做組重量、次數與體重。

技術：Python **Flask** ＋ **sqlite3**（單一資料庫檔）＋ **Jinja2** 模板＋少量 CSS ＋ **Plotly** 互動圖。

## 本機執行

```powershell
pip install -r requirements.txt
python -m flask --app app set-password      # 設定唯一的登入帳號密碼（密碼至少 8 碼）
python -m flask --app app seed-demo         # （選用）加入約 45 天的測試資料
python -m flask --app app run --host 0.0.0.0
```

電腦開 <http://127.0.0.1:5000>；同一個 Wi-Fi 下的 iPhone 開 `http://<電腦 IP>:5000`。
部署到 PythonAnywhere 請看 [DEPLOY.md](DEPLOY.md)。

快速檢查主要流程（用暫存資料庫，不動到真實資料）：

```powershell
python tests/smoke_test.py
```

## 功能對照（企劃書第四節）

| 功能 | 做法 |
|---|---|
| 1 組間快速記錄 | 「訓練」→ 選動作 → 器材切換鈕。重量／次數旁有大顆 −／＋（每台器材可設定每次加減幾公斤），數字鍵盤輸入；自動帶入日期、累計組數；熱身組另外標記。存完數值保留，相同的下一組再按一次即可（沿用）。每組都可修改或刪除。 |
| 2 前次表現查詢 | 進入動作即顯示同器材最近一次的日期與逐組公斤 × 次數；啞鈴標「單手」。沒紀錄的器材顯示「首次記錄」。 |
| 3 月度與長期曲線 | 「回顧」預設近 30 天，可延長到 60/90/180/365 天或全部。公斤與次數上下兩張圖共用日期軸；可選比較第 1/2/3 個正式組或當天最重組（熱身不列入）。加重或同重量多做幾下以橘色 ★ 標示並列出清單。點資料點看當天全部組別與生活簡記。體重另圖顯示，沒量的日子留白，畫出目標體重線。 |
| 4 生活與體重簡記 | 「簡記」填體重、昨晚睡眠（記在起床日）、飲食短記，可留白、可切換日期補記。首頁標示今天訓練與簡記是否已記錄。頁面附 iPhone「提醒事項」設定步驟與可複製的網址。 |
| 4+ 飲食營養估算（延伸） | 飲食短記照常寫一句話，例如「早餐蛋餅、午餐雞腿便當、晚餐鍋貼20顆」，`nutrition.py` 會拆出食物、數量、單位（支援「鍋貼20顆」「兩碗白飯」「白飯半碗」「雞胸肉200g」），再查食物表算出熱量、碳水、蛋白質、脂肪。打字時即時試算；查不到的食物列為「未知」、不猜數字，點一下就能新增到食物表，舊紀錄也會自動重算。內建約 80 種台灣常見外食，數值參考衛福部食藥署「食品營養成分資料庫」與常見份量，可自行修改。回顧頁有每日熱量與蛋白質圖及平均值。 |
| 4++ 吃夠了嗎（延伸） | `goals.py`：設定頁選方向（自動依目標體重判斷，或手動選增重／維持／減重），填性別、身高、年齡、活動量，以 Mifflin-St Jeor 公式算維持熱量，增重 +300、減重 −500；也可直接手動填熱量。蛋白質 = 最近體重 × 每公斤 g 數。熱量規則依方向相反：增重是下限、減重是上限、維持是 ±10%；蛋白質都是下限。今天還沒結束只顯示進度條（「還差 / 還可以吃」），不判斷不足；過去的日子標 ✓／不足／超過／?。有查不到的食物時，只在已知部分就能確定時才下結論。回顧圖畫出每天的目標線並統計達標天數。吉祥物仍只看有沒有記錄，不受吃得夠不夠影響。 |
| 5 吉祥物回饋 | 壺鈴「小鈴」，本週訓練日 +2、簡記日 +1，分 5 個階段長大；連續 3 天沒紀錄會變成想睡的樣子。規則只看有沒有記錄，不判斷飲食好壞（規則在 `mascot.py`，方便和受訪者討論後調整）。 |
| 6 登入保護 | 單一帳號密碼（雜湊存放），登入後保持一年。未登入的請求一律導向登入頁。 |

企劃書第五節的風險因應：

- **健身房網路不穩**：組間儲存走背景送出；失敗或逾時會保留欄位內容、標示「尚未儲存」並改成「重新送出」。
  草稿也暫存在手機上，關掉 App 再開仍會放回。每組帶唯一編號，重送不會重複寫入。
- **資料遺失**：「設定」可下載逐組紀錄與生活簡記兩份 CSV（Excel 可直接開）。
- **營養估算的限制**：企劃書原本把「食物熱量辨識」排除在本學期外，這裡是延伸功能。同一種食物各家份量差很多，
  數值只適合看長期趨勢；含查不到食物的日子會標示，月平均只計算每項都查得到的日子。
- **測試資料與真實紀錄區分**：測試資料全部標示「測試」，可一鍵清除且不影響真實紀錄。

## 檔案結構

```
app.py            路由、表單、登入、CSV、管理指令（set-password / seed-demo / clear-demo）
db.py             資料表與查詢（exercises / sets / daily / settings）
charts.py         用 Plotly 產生趨勢圖
nutrition.py      內建食物表與飲食短記解析（熱量、碳水、蛋白質、脂肪估算）
goals.py          每日熱量與蛋白質目標、增重／維持／減重的達標判斷
mascot.py         吉祥物成長規則與 SVG
demo.py           跨月測試資料
templates/        Jinja2 頁面
static/           style.css、app.js、App 圖示
tools/make_icons.py  重新產生圖示（需要 Pillow）
tests/smoke_test.py  主要流程檢查
instance/         資料庫 fitness.db 與 secret_key（自動建立，不要上傳到公開的地方）
```
